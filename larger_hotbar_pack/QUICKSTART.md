# ⚡ SCHNELLSTART / QUICK START

## 🇩🇪 Deutsch

### In 3 Schritten zur größeren Hotbar:

1. **📁 Kopiere den Ordner**
   ```
   larger_hotbar_pack → Dein Handy/Tablet
   ```

2. **📂 Verschiebe nach**
   - **Android**: `Android/data/com.mojang.minecraftpe/files/games/com.mojang/resource_packs/`
   - **iOS**: `Minecraft PE/games/com.mojang/resource_packs/`

3. **✅ Aktiviere in Minecraft**
   - Einstellungen → Globale Ressourcen → "Größere Hotbar Pack" aktivieren

### Das war's! 🎉

## 🇬🇧 English

### Get larger hotbar in 3 steps:

1. **📁 Copy the folder**
   ```
   larger_hotbar_pack → Your phone/tablet
   ```

2. **📂 Move to**
   - **Android**: `Android/data/com.mojang.minecraftpe/files/games/com.mojang/resource_packs/`
   - **iOS**: `Minecraft PE/games/com.mojang/resource_packs/`

3. **✅ Activate in Minecraft**
   - Settings → Global Resources → Activate "Größere Hotbar Pack"

### That's it! 🎉

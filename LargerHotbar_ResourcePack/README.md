# Larger Hotbar UI Resource Pack für Minecraft Bedrock Edition (Mobile)

## Beschreibung
Dieses Resource Pack vergrößert die Hotbar, Herzen, Hunger-Leiste und XP-Bar für eine bessere Sichtbarkeit auf mobilen Geräten (Handys/Tablets). Perfekt optimiert für Minecraft Bedrock Edition auf dem Handy!

## Änderungen
- **Hotbar**: Von 40px auf 60px Höhe vergrößert
- **Hotbar-Slots**: Von 20x22px auf 30x33px vergrößert  
- **Herzen**: Von 9x9px auf 13x13px vergrößert
- **XP-Bar**: Von 5px auf 7px Höhe vergrößert
- **Ausgewählter Slot-Rahmen**: Von 24x24px auf 36x36px vergrößert
- **Inventar-Button**: Von 16x16px auf 24x24px vergrößert

## Installation
1. Kopiere den gesamten Ordner `LargerHotbar_ResourcePack` in:
   - **Android**: `Android/data/com.mojang.minecraftpe/files/games/com.mojang/resource_packs/`
   - **iOS**: `On My iPhone/Minecraft/games/com.mojang/resource_packs/`
   
2. Starte Minecraft Bedrock Edition

3. Gehe zu **Einstellungen** → **Globale Ressourcen**

4. Aktiviere das Pack "Larger Hotbar UI"

5. Starte das Spiel neu oder lade die Welt neu

## Funktionen
- ✅ Alle Buttons funktionieren weiterhin (Inventar, etc.)
- ✅ Hitboxen der Inventar-Slots sind korrekt skaliert
- ✅ Kompatibel mit Minecraft Bedrock Edition 1.20+
- ✅ Optimiert für mobile Geräte (Handy/Tablet)

## Kompatibilität
- Minecraft Bedrock Edition Version 1.20.0 oder höher
- Funktioniert auf Android und iOS
- Kompatibel mit anderen Resource Packs (abhängig von deren Änderungen)

## Hinweis
Dieses Pack ändert nur die Größe der UI-Elemente, nicht die Texturen selbst. Die Skalierung erfolgt automatisch durch Minecraft.
